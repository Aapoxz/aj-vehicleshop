# aj-vehicleshop
Really simple esx/ox_lib fivem vehicle shop to buy vehicles and stores them on database. (should work with every garage)

Key features:
- Only cash allowed!
- Simple vehicle preview.
- esx / ox_lib.
- ox_inventory ONLY!!! (you need it or it wont work).
